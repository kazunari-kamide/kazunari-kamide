## 上出 一就 / Kazunari Kamide
金沢在住。地域の「使われていないデータ」を、使える形にして公開しています。
Based in Kanazawa, Japan. I turn local data nobody could use into something people can.

### 作ったもの / Projects
- **酒結び** — https://find-sake.me/
  数問の診断で、その店にある日本酒から1本を選ぶ（8言語）。日本酒ハッカソン2026 準優勝（金沢市長賞）。
  金沢の酒屋・居酒屋で試験運用中。
  A quiz that picks one sake from what the bar actually stocks. 8 languages. Runner-up, Ishikawa Sake Hackathon 2026.
- **石川の地酒 味わいデータ（CC BY 4.0）** — https://github.com/Sake-Musubi/ishikawa-sake-data-sakemusubi
  761銘柄のスペックと7軸の味わい値。3つの蔵が直接確認。Claude Code で作成し、検証スクリプトと目視で確認。
  Open dataset of 761 sake, built with Claude Code and verified by scripts, by hand and by brewers.
- **プロポナビ** — https://proponavi.com/
  自治体のプロポーザル案件を集めて、PDFの中身まで検索できる無料サイト（42自治体・4,849件）。
  Free search engine for Japanese municipal procurement proposals, including full PDF text.
